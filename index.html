Canvas Course Cleanup

A local desktop utility for safely cleaning and reorganizing Canvas course content. The tool converts external-tool video assignments into regular Canvas pages while preserving important module details, then archives unused or unpublished content.

  • Preserves module position, indentation, links, and publication state
  • Moves unpublished items into a selected archive/unused module
  • Uses verification steps before changing original course content
  • Keeps the Canvas access token in memory rather than writing it to disk
