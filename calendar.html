Canvas Calendar Pacing Automation

This desktop automation tool was built to reduce the repetitive work involved in managing Canvas course pacing. It turns course-calendar decisions into repeatable Canvas updates across multiple classes.

What it does

  • Updates Canvas due dates and pacing information.
  • Handles different Canvas course-item types and scheduling rules.
  • Works around real school-calendar constraints, including course deadlines and non-instructional events.
  • Supports repeatable updates across multiple courses instead of requiring the same changes by hand.

Why I built it

Maintaining several online courses can require the same date and scheduling changes to be repeated again and again. I built this tool around that real workflow so I could make those updates more consistently and spend less time on repetitive course maintenance.

Technologies

Python Canvas REST API Automation
